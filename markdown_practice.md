# My Dream Coding Project 🌱 
## Project Overview
**EcoTrack** is an app designed to help users *track their daily carbon footprints* and make them small, sustainable choices that add up to the big impact. It's built using **HTML, CSS**and **Javascript**-but one day, I want to expand it into afull web platform!

---

## Project Goals
- Build a user-friendly dashboard that tracks:
 - 🌿 *Energy use*
 - 🚗 *Transportation impact*
 - 🍔 *Food consumption patterns*
- Display personalized reports using:
 - `console.log()` to debug progress
 ``` if(carbonScore <50) {
     console.log("Great job staying eco friendly!");
 } else {
    console.log("Let's find ways to reduce your footprints");
 } 
```
